# TaskFlow

TaskFlow تطبيق Flutter لإدارة المهام محليًا على Android، بواجهة عربية/إنجليزية ووضع فاتح/داكن. قاعدة SQLite تحفظ المهام على الجهاز ولا يتطلب التطبيق إنشاء حساب أو اتصالًا بالإنترنت. لا يتضمن هذا الإصدار جدولة تذكيرات الإشعارات؛ ولا ينبغي اعتباره منبهًا.

## تنزيل المشروع ورفعه إلى GitHub من الهاتف
1. نزّل `TaskFlow-Flutter-Android.zip` وفك ضغطه بتطبيق الملفات على Android (مثل Files أو ZArchiver).
2. افتح GitHub في المتصفح أو التطبيق وسجّل الدخول، ثم اضغط **New repository**.
3. أدخل اسمًا مثل `TaskFlow` واختر **Private** أو **Public**. خصوصية المصدر لا تؤثر على تشغيل APK بعد تنزيله.
4. ارفع محتويات مجلد المشروع إلى جذر المستودع، مع التأكد من ظهور `.github/workflows/android-build.yml`.
5. ارفع الملفات على دفعات إذا واجهت حدود حجم/عدد ملفات الواجهة الهاتفية. لا ترفع مجلدات `.dart_tool` أو `build`.
6. افتح تبويب **Actions** وفعّل workflows إن طلب GitHub ذلك. شغّل **Android APK** عبر **Run workflow** أو ادفع commit جديدًا.
7. انتظر علامة النجاح الخضراء. افتح تشغيل workflow الناجح، ثم نزّل artifact باسم `TaskFlow-Android-APK`.
8. فك ضغط artifact، ثم افتح APK على Android. قد تحتاج السماح للمتصفح/مدير الملفات بتثبيت تطبيقات من هذا المصدر.

## البناء والتعديل
يستخدم workflow Flutter stable وJava 17 ويشغّل `flutter pub get`, `flutter analyze`, `flutter test` ثم يبني APK Release. الإصدارات تحددها ملفات المشروع وworkflow؛ عند تغيير إصدار Flutter، حدّث workflow واختبره. الحد الأدنى المضبوط في Gradle هو Android 9 (API 28).

للبناء محليًا على بيئة Flutter: `flutter pub get`, `flutter analyze`, `flutter test`, ثم `flutter build apk --release`.

## البيانات والخصوصية
المهام مخزنة بقاعدة SQLite محلية. تصدير JSON يشارك الملف باستخدام قائمة المشاركة في النظام. الاستيراد يستبدل المهام الحالية بعد التحقق من بنية السجل وبعد تأكيد المستخدم. خذ نسخة احتياطية قبل الاستيراد. لا توجد مزامنة سحابية.

## القيود الحالية
إشعارات التذكير، الفئات المخصصة، تصدير/استيراد الفئات، وتحديد بداية الأسبوع غير مضمنة في هذا الإصدار. لا يوجد توقيع نشر مخصص؛ APK الذي ينتجه GitHub Actions مخصص للتثبيت والاختبار، وللنشر في متجر يلزم إعداد توقيع release خاص.
